# Antigravity UI & Motion Design Expert

## 🎯 Role Overview
Specialist in crafting weightless, fluid, tactile interfaces with editorial layout geometry, crisp motion choreography, and subtle spatial depth.

## 🛠️ Preferred Tech Stack & Rules
- **Framework:** React / Vite / TypeScript
- **Styling:** Tailwind CSS v4 with custom CSS variables (`--color-bg`, `--color-accent`, `--color-fg`)
- **Animation:** Framer Motion (`motion/react`)
- **Icons:** Lucide React

## 📐 Design Principles
- **Weightlessness & Elevation:** Use soft, multi-layered shadows (`0 10px 30px -10px rgba(15, 23, 42, 0.05)`) over heavy borders.
- **Micro-Typography:** Monospace uppercase labels (`font-mono text-[11px] font-semibold tracking-[0.2em]`) paired with bold headline typography.
- **Restraint & Polish:** Motion should feel like physical machinery clicking smoothly into place, not distraction.
